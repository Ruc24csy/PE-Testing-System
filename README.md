# 体育成绩录入平台

面向承担本科公共体育课的教师：按学期导入课程信息与名单，教师在线录入体测原始成绩、运动技能评定和平时成绩，系统按 2014 年《国家学生体质健康标准》逐人查表换算，自动算出体测小计与课程总成绩，并导出 Excel 供厂家和教育部上报。

## 功能一览

| 角色 | 能做什么 |
|---|---|
| 教师 | 统一身份认证登录；按学期查看本人教学班（课程、校区筛选，按星期节次排序）；类 Excel 表格录入（键盘优先、整列粘贴、批量置状态、自动暂存、断网恢复、撤销）；即时换算与档位提示；查看评分表和每个分数的计算过程；标记“信息有误”；提交前四类校验；提交、申请撤回；导出 Excel；下载模板整班上传与回退 |
| 体育部管理员 | 新建学期、设当前学期、为以往学期开放补录窗口；导入三张表（自动识别表头、字段映射并记住、预检报告、覆盖／新增／追加／重建）；待确认清单（年级冲突、上课年级为空、一人多条选课、无学籍、性别异常、特殊学籍），确认标准档并写入年级校正名单；为“教师待补”教学班指定教师；审核撤回申请；按学期查询操作日志；导出全学期成绩；设置管理员 |

计分口径（与需求文档一致）：

- 单项得分查表取达到的最高档；耐力跑、50米跑用时越短越好，其余越大越好；低于10分档记0分。
- 加分只适用于耐力跑和引体向上／仰卧起坐，单项最高 +10 分；体测小计最高 32 分。
- 折算分＝单项得分×权重，两位小数；课程总成绩＝体测小计＋运动技能评定＋平时成绩，四舍五入一位小数。
- 免测不参与换算；缓测计为缺项；缺考、作弊、违纪记 0 分。空值不按 0 分处理。
- 标准档逐人判定：年级校正名单 > 选课表“上课年级” > 学号推算；上课年级与学号推算跨越大二／大三分界时进入待确认清单，暂按上课年级计算，班级有待确认学生时不能提交。

## 本地运行

需要 Python 3.10 及以上。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
PE_ADMIN_STAFF_NOS=admin .venv/bin/uvicorn app.main:app --port 8000
```

打开 http://127.0.0.1:8000 ，开发模式下输入工号即可登录（`admin` 为管理员）。到“体育部管理 → 学期管理”新建学期，再到“课程信息导入”依次导入学生基础数据表、课程安排表、学生选课表。

也可以用命令一次导入三张表：

```bash
.venv/bin/python scripts/manage.py import 2026-2027学年秋季学期 课程安排.xlsx 学生选课.xlsx 学生基础数据.xlsx
```

## 配置（环境变量）

| 变量 | 说明 | 默认 |
|---|---|---|
| `PE_AUTH_MODE` | `cas`＝数字人大统一身份认证；`local`＝工号＋平台口令（统一认证接入前临时使用，口令由体育部在“账号”页批量生成发放）；`dev`＝输入工号即登录，仅限开发 | `dev` |
| `PE_CAS_SERVER_URL` | 统一身份认证 CAS 地址，如 `https://cas.example.edu.cn/cas` | 空 |
| `PE_CAS_SERVICE_URL` | 本平台回调地址，如 `https://域名/auth/cas/callback` | 空 |
| `PE_ADMIN_STAFF_NOS` | 体育部管理员工号，逗号分隔（也可在管理端设置） | 空 |
| `PE_DATA_DIR` | 数据目录（数据库、上传文件、会话密钥） | `./data` |
| `PE_DATABASE_URL` | 数据库地址，默认 SQLite；可换成 PostgreSQL 等 | `sqlite:///data/pe_scores.db` |
| `PE_SECRET_KEY` | 会话签名密钥，不设则自动生成并保存在数据目录 | 自动 |
| `PE_HTTPS_ONLY` | 设为 `1` 时会话 Cookie 只走 HTTPS 并发送 HSTS | `0` |

统一身份认证按标准 CAS 协议对接（`/login` 跳转、`/serviceValidate` 校验，工号取 `cas:user`）。数字人大应用审批通过、拿到 CAS 地址后设置上面三项即可；如果数字人大给的是 OAuth2 等其他协议，需要在 `app/auth.py` 补一个对应的回调。

统一认证接入前用 `local` 模式：体育部管理员在“体育部管理 → 账号”为本学期全部任课教师一键生成初始口令，下载表格分发；教师首次登录须修改。切换到 `cas` 后，本地口令只对管理员有效。

应急管理员（统一认证不可用时使用本地口令）：

```bash
.venv/bin/python scripts/manage.py create-admin <工号> <姓名>
```

会打印随机初始口令，首次登录须修改（不少于8位，含数字、大写、小写、特殊字符中的至少三类）。本地口令连续失败 5 次锁定 15 分钟并记录来源 IP。

## 代码结构

- `app/scoring.py`：原始成绩解析、查表换算、加分、舍入（纯函数）
- `app/standards/gb2014.json`：内置评分表，由 `tools/build_standards.py` 从两份评分表 docx 生成
- `app/grading.py`：学生年级判定与“一人一档”标准档快照
- `app/importer.py`：三张表的表头识别、字段映射、预检与写入
- `app/services.py`：录入、校验、留痕、提交
- `app/main.py`：网页接口；`app/static/`：前端页面（无需构建）
- `scripts/manage.py`：建表、建管理员、命令行导入、备份
